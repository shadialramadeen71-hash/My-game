# My-game

- `index.html`: لعبة سوبر مان ضد بات مان
- `series.html`: مسلسل كرتوني ثلاثي الأبعاد **«فريق النجوم»** (الحلقة ١: كريستالة النور)
  - أبطال: برق ⚡ (السرعة)، صخر 🪨 (القوة)، نسمة 🌪️ (الرياح)، والشرير الدكتور ظلام
  - شخصيات ثلاثية الأبعاد بأسلوب Blender: خامات واقعية (PBR)، إضاءة بيئية، ظلال ناعمة، توهّج Bloom، وتدرّج ألوان AgX
  - موسيقى ومؤثرات صوتية مولّدة داخل المتصفح (Web Audio)
  - افتح الملف في المتصفح واضغط «شاهد الحلقة»
