# My-game

## 🎬 The Buckleys — Episode 1: "Ticket to Nowhere"

An adult-animation-style cartoon episode (thick ink outlines, flat colours, big-chinned
suburban dad, talking pet) drawn, animated, scored and voiced **entirely with code**.

Open [`cartoon/index.html`](cartoon/index.html) in a browser and press **▶ Watch Episode**.

- **Characters** (all original): Gary (the dad), Donna (the mom), Tyler (the son),
  Mr. Whiskers (the sarcastic cat) and Brenda (the bored store clerk).
- **Animation**: jointed skeletons (hips, knees, ankles, shoulders, elbows, hands),
  walk cycles, sitting, kick-line dancing, gestures, blinking, lip flaps, camera cuts and zooms.
- **Locations**: living room (day & night), the street outside the house, a car drive with
  parallax scrolling, a convenience store, and a hot-dog-contest cutaway gag.
- **Sound**: English voice acting via the browser's Web Speech API (different voice,
  pitch and speed per character), subtitles, a theme song and sound effects via Web Audio.

Controls: Pause / Restart / Voices on-off / Subtitles / Fullscreen (Space = pause).
Voices depend on the speech voices installed on the device; Chrome, Edge and Safari work best.

The original fighting game is still at [`index.html`](index.html).
